# VBA Challenge – Module 2

This project analyzes quarterly stock data using a custom VBA script.

## Features
- Loops through every worksheet
- Calculates quarterly and percent change
- Sums total volume
- Highlights positive and negative trends
- Identifies greatest % increase, decrease, and total volume

## Files
- `StockSummaryWithStyle.bas` – main analysis macro
- `ResetSheets.bas` – clears previous outputs
- `alphabetical_testing.xlsx` – used for testing
